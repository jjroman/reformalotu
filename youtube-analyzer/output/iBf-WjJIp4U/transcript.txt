En este vídeo te voy a mostrar cómo
vamos a dar un aire nuevo a nuestras
paredes alicatadas, sin necesidad de obra,
simplemente pintando con una imprimación especial.
Antes de empezar a pintar es necesario
limpiar bien el soporte, tanto de polvo
como de manchas. Es muy importante para que nuestra imprimación tenga la
máxima adherencia. Para ello vamos a
utilizar este limpiador específico.
Después de aplicado el producto
aclaramos con agua abundante y dejamos secar.
Ahora sí podemos decir que estos
azulejos están listos para pintar sobre ellos.
Este azulejo es un esmalte cerámico.
El esmalte cerámico es como
el vidrio, no tiene ningún tipo de poro,
con lo cual las pinturas convencionales
no tienen agarre. Para solucionarlo
vamos a utilizar esta imprimación que
nos va a proporcionar la adherencia necesaria.
La podemos aplicar con brocha, con rodillo o a pistola, siguiendo las recomendaciones del fabricante.
Te voy a contar cómo vamos a pintar el cuarto de baño.
Tenemos unas paredes de color malva.
El fabricante nos ha propuesto una serie de colores en la imprimación y he elegido este verde.
Nos va a venir bien para
hacer la moldura y la parte inferior del azulejo.
La parte central la vamos a imprimar con blanco, porque queremos
construir dos tonos de malva. Para empezar vamos a delimitar las zonas.
Vamos a verter el producto sobre una gaveta.
Para pintar vamos a utilizar este tipo de rodillo de espuma para que no se
note la huella de la herramienta que
vamos a utilizar.
Nos podemos a pintar directamente.
Vamos a utilizar la brocha para
que penetre mucho mejor la pintura en estos recovecos.
No te preocupes si no cubre lo
suficiente, hay que dar dos manos.
Hemos dado dos manos de verde y lo hemos dejado secar. A continuación vamos a
quitar la cinta que delimitaba el verde,
porque vamos a colocar una nueva cinta
para delimitar con el blanco.
Ya hemos terminado de poner cinta a
la zona central, que es la que vamos a
imprimar con el color blanco.
¿por qué vamos a pintar con está imprimación en blanco?
Porque el color que queremos es
un color claro, con lo cual vamos a
ganar poder de cubrición a la vez que
vamos a tapar este color tan intenso.
Si hubiéramos decidido dejar los
azulejos en blanco
bastaría con volver a dar otra mano de
imprimación.
Hemos imprimado la superficie y ya la
tenemos completamente seca.
Vamos a aprovechar la cinta que delimita
a este color verde.
Hemos hecho dos colores.
En este caso he decidido pintarlo con un
esmalte de poliuretano  al agua,
pero puedes pintarlo con un epoxi o con una pintura sintética,
pero debes esperar como mínimo 48
horas.
Vamos repartiendo la pintura lo más homogéneamente posible, insistiendo en las juntas.
Es importante pasar el rodillo en
horizontal y en vertical para que no se
note la huella del rodillo.
Está seco el color
más claro, a continuación vamos a
delimitar la zona que queremos pintar
con el color más oscuro.
El cuarto de baño es el mismo pero su aspecto ha cambiado totalmente.
Si no te gusta el color que has elegido,
pasados siete días, puedes pasar una lija fina y cambiar totalmente el color.
