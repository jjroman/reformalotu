Las grasas, las humedades, el hollín afectan
a nuestras paredes.
Intentamos resolverlo con pinturas
convencionales pero vuelven a salir.
En este tutorial te voy a mostrar, con tres
ejemplos, como con pinturas especiales,
vamos a eliminar totalmente las manchas.
En este caso, hemos figurado una serie de
manchas en la pared con un soplete.
Vamos a ver cómo podemos solucionarlo.
Primero vamos a coger una espátula y
vamos a raspar las zonas de pintura que
están mal adheridas.
A continuación vamos a pasar un cepillo
a la pared para eliminar físicamente el
hollín.
Una vez eliminado el hollín,
vamos a aplicar la pintura. Como lo vamos
a hacer a pistola, vamos a seguir
las recomendaciones del fabricante y lo
vamos a diluir, hasta un máximo de un 5
por ciento, con agua.
Antes de empezar a trabajar, te quiero
hacer dos recomendaciones:
la primera es la distancia, vamos a mantener
una distancia entre 20 y 30 centímetros.
La segunda recomendación es, como
vamos a trabajar en franjas, la franja que
estamos pintando deberá montarse sobre
un poco sobre la anterior, para que la
superficie quede lo más cubierta posible.
En este caso tenemos una pared muy
afectada por la humedad. Ya la hemos
dejado secar para poder repararla.
A continuación una vez que está seca,
vamos a raspar.
Para raspar, lo primero es pasar la
espátula de manera plana, así quitamos
la cascarilla más evidente. Una vez
que hayamos hecho eso, vamos a insistir
en las zonas peor adheridas.
Simplemente con el pico de la espátula,
ayudándonos con  la otra mano.
A continuación vamos a preparar un
fijador de fondos. Vamos a
echar una pequeña cantidad y
a seguir las instrucciones del fabricante.
En este caso vamos a echar el doble de agua.
Como veis, estoy reparando los
desperfectos más grandes de la pared.
Una vez emplastecido, vamos a lijar la
superficie.
Vamos a eliminar las imperfecciones que
hayamos dejado con las espátulas.
Una vez lijado, vamos a eliminar el polvo
y vamos a dar un fijador para
consolidar el fondo.
Ya tenemos la mezcla hecha,
a continuación vamos a aplicar nuestro
fijador con un rodillo de hilo.
Una vez que tengamos nuestro fijador
seco, aunque lo veamos brillante ya está seco,
vamos a aplicar una pintura
especial para ambientes húmedos.
Vamos a verter la pintura. Como podéis ver,
la pintura está espesa. Vamos a
echarle el disolvente adecuado.
La primera operación será perfilar,
recortar la parte de arriba, nuestros
enchufes, y la parte de abajo.
Una vez que hayamos terminado de
recortar, vamos a pintar. El rodillo que
hemos elegido es de lana. La lana
penetra mucho mejor sobre esta textura.
Para introducir el rodillo y que no nos
gotee,  mojamos la parte más superficial
del pelo del rodillo y lo escurrimos
sobre las paredes del cubo.
Ya hemos terminado de pintar, solamente
nos queda dejarla secar.
Estoy terminando de empapelar, porque a
continuación vamos a pintar el techo.
En este caso, vamos a pintar directamente nuestra
mancha de humedad con pintura plástica.
¿Por qué he hecho esto? Para demostrarte que
no se debe pintar con una pintura
normal sobre una mancha de humedad.  Es necesario aplicar
una pintura especial. Lo vamos a dejar
secar para que podáis ver cuál es el resultado.
Como veis, no ha funcionado.
Vuelve a salir la mancha después de
aplicar una pintura plástica normal.
Es necesario aplicar una pintura que sea
quitamanchas. En este caso,  primero vamos
a delimitar los rincones y las esquinas con el brochín.
Una vez terminado de recortar, vamos a
utilizar el rodillo. En este caso vamos
a trabajar en varias direcciones,
para que la toda superficie quede lo más
homogénea posible, a la vez que vamos a
conseguir que no se nos note la huella
del rodillo.
Ya hemos terminado. Hemos pintado el techo.
Éste es el aspecto que tiene esta
pintura.
Por supuesto, si quieres cambiarle el
color o darle otro aspecto diferente,
puedes hacerlo.
Espero que, después de este vídeo, no
tengan más problemas con las manchas.
